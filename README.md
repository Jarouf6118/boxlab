# Boxlab

Kostenloses 3D-Mockup-Programm für Verpackungen (Windows 10/11, 64 Bit) von [The Companion Consulting](https://thecompanion.consulting/programme/boxlab/).

Lade deine Druckmotive oder den kompletten Druckbogen (SVG/PDF), drehe und beleuchte die Box und exportiere Bild oder Video. Alles läuft lokal auf deinem Rechner, deine Dateien werden nicht hochgeladen.

**Alle Infos, Funktionen und Anleitung: https://thecompanion.consulting/programme/boxlab/**

## Download

Die aktuelle Version findest du unter **[Releases](../../releases/latest)**:

- `Boxlab-Setup.exe` – Installer für Windows
- `Boxlab-Update.boxupd` – Update-Datei, falls du Boxlab schon installiert hast (im Programm unter *Export → Programm-Update → Update-Datei installieren…*)

## Windows zeigt eine Warnung?

Boxlab ist nicht mit einem kostenpflichtigen Zertifikat signiert. Beim ersten Start meldet Windows „Der Computer wurde durch Windows geschützt“. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Auch dein Browser kann beim Download warnen, bestätige dort „Behalten“.
